# ctf-fuck-screenrecorder

## 这是什么

这是一个无终端窗口的python脚本，专为CTF场景设计，不会在windows任务栏留下任何图标，并且无法被obs-studio等录屏软件录制。便于你在各种需要录屏的CTF比赛中，使用浏览器出网查资料/问AI

## 如何使用

如果你的windows电脑已经有python环境，那直接点击运行即可。cfs_kbhook.pyw是hook键盘的版本，输入中文时，输入法本身可能会被录制到，所以为了输入法导致的露馅，可以用hook键盘的版本，按自己的使用场景决定。

**建议录屏时关闭鼠标指针的录制**

## 为什么需要

某些线上比赛，靠"录屏"实现阻止选手出网查询资料问AI，显得十分愚昧可笑。既无法保证比赛公平性，也侵犯了选手的个人隐私。**出发点是反作弊，落点却成了防学习和侵犯选手隐私，执行上更是防君子不防小人。**

法律上，根据《个人信息保护法》第16条规定，不得以个人不同意处理其个人信息或撤回同意为由拒绝提供产品或服务，除非该处理属于提供服务所必需。也就是说"不同意录屏就不许参赛"这句话本身不能站住，办赛方没有任何权力要求选手必须录屏。

执行上，99%的CTF做不到真断网、真监考、真查设备，最后全靠自觉。于是规则变成两层：较真的选手自我阉割，想作弊的人手机一开照样抄，最后惩罚的是老实人。这种"表演式公平"，与其说是规则，不如说是组织者给自己省事甚至开后门，关系户没进就猛查录屏，鸡蛋里挑骨头，多ban几队。

这样的规则也没有任何意义，查手册，读CVE翻GitHub，本来就是安全行业的日常，人与AI协作也会是以后的发展趋势。把一个本来极度依赖联网的场景做成"闭卷考试"，训练一种根本不存在的技能，是在培养新时代做题蛆吗？
